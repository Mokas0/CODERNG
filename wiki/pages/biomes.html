Global Biomes

Temporary world events that unlock exclusive auras.

How Biomes Work

  • Biomes are global events (same for all players, powered by Supabase)
  • A Discord bot triggers new biomes on a schedule
  • When active, a banner appears with the biome type and countdown
  • During an active biome, every roll has a 1/500,000 chance to trigger a bonus biome aura roll
  • NULL biome has a higher 1/10,000 chance
  • Biome auras are NOT in the normal roll pool — only obtainable during events

NULL Biome

1/10,000 per minute

  • One unique aura: ID 9930 NOTHING (9Q rarity)
  • Has isNull: true flag
  • Higher roll chance (1/10,000 vs 1/500,000) during the event
  • Special void-themed cutscene
Rarity Note

Biome aura rarities are in the quintillion range (above MAX_SAFE_INTEGER). These values are for display only and don't affect weight calculations since biome auras use a flat 1/500,000 roll chance instead.
