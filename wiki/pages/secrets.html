Secret Auras

Hidden auras that can't be rolled normally.

How to Get Them

  • Secret auras are triggered ONLY by using the Ultraluck Potion (Benny exclusive, 5,000 coins)
  • Each use has a 1/10,000,000 chance to spawn a secret aura
  • If triggered, one of the 10 secret auras is randomly selected (so each individual aura is effectively 1/100,000,000)
  • Triggers an unskippable cutscene (10 second duration, 8 second minimum view)
  • Rarity displays as "SECRET" (rarity value is 0)
