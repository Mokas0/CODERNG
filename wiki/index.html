Game Overview

CODERNG is a browser-based RNG aura rolling game. Players roll for items spanning rarities from 1/2 to 1/9 quadrillion. The game features multiple shops, a luck system with potions and gear, global biome events, hidden Elder and Secret auras, a casino, a player marketplace, quests, and a tycoon clicker.

Everything runs in the browser with Supabase powering multiplayer features.
